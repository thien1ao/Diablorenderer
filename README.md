# Tiny Renderer

A software renderer implemented in C++ by following the
[Tiny Renderer tutorial series](https://github.com/ssloy/tinyrenderer)
by Dmitry Sokolov (ssloy), extended with an interactive SDL2 viewer.

## Features

- Interactive SDL2 viewer with mouse-controlled camera orbit
- Textured rendering with Phong lighting and normal mapping
- Wireframe overlay
- Vertex normal visualization
- White-material mode for inspecting lighting
